## 1. 한 줄 정의

**앱·챗봇이 외부 LLM API(Gemini·OpenAI 등)로 프롬프트를 보내기 전에, 한국어 개인정보·
자격증명·기밀 표식과 프롬프트 공격을 사용자 기기 안에서 찾아 막거나 가리는 오픈소스
검사기.** 검사기 자체는 어떤 데이터도 외부로 보내지 않는다.

참고 솔루션은 SecureBridge(AhnLab CloudMate) 계열의 GenAI DLP다. 가림은 그중 **한국어
탐지 엔진과 마스킹·복원 경로**에 집중한 공개 연구 산출물이다. 조직 관리 콘솔·사용자별
정책·브라우저 확장 같은 조직 배포 기능은 범위 밖이다(§9).

## 2. 동작 구조

```
[내 앱·챗봇]  시스템 프롬프트 + 사용자 입력 + RAG 문서 + 도구 호출 기록
      │
      ▼
┌─ 가림 검사기 (로컬) ─────────────────────────────────────────┐
│ L0  규칙 · 7단계 가역 정규화 · 체크섬           항상, 수 ms        │
│ L1  공유 인코더 + 헤드 4 (PII NER · 공격 4-way · 보조 2)  ONNX INT8 │
│ L2  Gemma 4 E2B 판정기 (thorough 모드, 루프백 llama-server)     │
│ 판정  allow / mask / warn / block   ·   볼트(가역 토큰)           │
└──────────────────────────────────────────────────────────────┘
      │  block 이면 보내지 않음 · mask 면 <PHONE_1> 처럼 가린 채로
      ▼
  Gemini API · OpenAI API (OpenAI 호환 엔드포인트)
      │
      ▼  응답의 토큰을 원문으로 복원 (조사 교정 포함) — 본문과 함수 인자 모두
[내 앱]
```

**쓰는 방식 셋**: Python 라이브러리(`Inspector().check(...)`, 본체), CLI(`garim check` /
`garim scan`), OpenAI 호환 로컬 프록시(`garim proxy` — 앱은 `base_url`만 바꾼다).

**핵심 설계 — 가역 정규화 후 재검사.** 자모 분해(`ㅇㅣㅈㅓㄴ`), 된소리화(`이쩐 찌시`),
제로폭 문자, 전각·동형 문자, 한자 치환, 띄어쓰기 파괴, base64 같은 한국어 우회를
분류기가 아니라 **결정적 정규화**로 되돌린 뒤 같은 규칙과 모델에 다시 태운다. 정규화는
원문 오프셋을 보존하므로(1:N 유니코드 확장 포함) 마스킹 위치가 원문에서 정확하다.

**실패 방향을 못박았다.** L0 예외와 검사하지 못한 입력 꼬리는 차단, 모델 계층(L1·L2)
실패는 L0 결과로 판정하되 `degraded=true`와 사유를 반드시 돌려준다. 조용한 성능 저하를
만들지 않는 것이 원칙이다.

## 3. 무엇을 찾는가

| 축 | 예 | 처리 |
|---|---|---|
| 한국 식별번호 | 주민·외국인등록번호(체크섬+생년월일·성별 정합), 여권, 운전면허, 사업자·법인번호, 건강보험, 계좌 | 주민·외국인은 block, 나머지 mask |
| 공통 PII | 카드(Luhn), 전화, 이메일, IP | mask |
| 문맥 PII (L1) | 성명, 주소, 사번류 | mask |
| 시크릿 | 클라우드·결제·국내 플랫폼 키(토스·카카오·NCP·공공데이터포털·NPKI), 고엔트로피 | block / warn |
| 기밀 표식 | `[대외비]`, `영업비밀`, `보안등급: 기밀` (위치 가중치) | warn |
| 공격 | 인젝션, 간접 인젝션(RAG·도구 출력), 탈옥, 시스템 프롬프트 유출 + 한국어 은닉 기법(자모·초성·된소리·띄어쓰기·한자·제로폭·동형·인코딩) | warn (정책으로 block 가능) |

공격은 **의도 축 × 은닉 축**으로 분해한다. 같은 의도가 된소리화로 숨었는지, 자모로
숨었는지를 따로 보고해 어떤 우회에 약한지가 지표로 드러난다.

## 4. 모델과 라이선스 — Google 모델을 어디에 쓰는가

| 계층 | 모델 | 라이선스 | 왜 |
|---|---|---|---|
| L1 백본 | `skt/A.X-Encoder-base` (한국어 ModernBERT, 0.15B) | Apache-2.0 | 토큰 분류에는 양방향 인코더가 필요하다 |
| **L2 판정** | **`google/gemma-4-E2B-it`** (Q4_K_M GGUF, 온디바이스) | **Apache-2.0** | 정책 프롬프트로 판정하는 생성 모델 자리 |
| **공격 라벨 교사** | **Gemma 4 E2B** + kanana-safeguard-prompt-2.1b + Qwen3Guard-Gen-4B | Apache-2.0 | 클래스별 2표 합의로 공격 라벨 증류 |

**Gemma 4 가 L1 에 들어가지 못한 이유는 조사로 확인했다.** transformers 의 Gemma 4 에는
분류 헤드가 없고(인과 마스크 생성 모델, 임베딩 포함 5.1B), Gemma 계열 인코더 파생
(EmbeddingGemma·T5Gemma 2)은 Gemma ToU·gated 라 "오픈 라이선스" 조건을 잃는다. 그래서
**판별은 인코더, 생성·판정은 Gemma 4** 로 역할을 나눴고, Gemma 4 는 런타임 L2 판정기와
학습용 교사 두 자리에 들어간다. 판정 프롬프트는 교사와 런타임이 한 출처를 공유한다.

**온디바이스 실행.** Gemma 4 E2B bf16 은 M1 16GB 에서 스왑에 빠져 쓸 수 없었다(4행 10분
초과). 고정 revision 가중치를 llama.cpp 로 GGUF(Q8_0 → Q4_K_M, 3.4GB) 변환해 루프백
서버로 띄운다. 판정기는 루프백 주소만 받는다 — 비루프백 목적지는 생성 시점에 거부한다.

모든 모델·데이터는 **exact revision 과 라이선스를 레지스트리에 고정**하고 다운로드 후
SHA-256 manifest 로 검증한다. 모델 자산(백본 · 교사 · 판정기)은 Apache-2.0 만 쓴다. 학습 데이터에는
KLUE-NER(CC-BY-SA-4.0)가 들어 있어 L1 가중치는 CC-BY-SA-4.0 으로 배포한다([MODEL_CARD_L1.md](MODEL_CARD_L1.md)).

## 5. 학습 방법

**공동 멀티태스크.** 한 인코더에 헤드 4개를 붙여 한 번에 학습한다 — PII 토큰 분류(14
엔티티 BIO, 29 라벨), 공격 4-way(NONE/INJECTION/JAILBREAK/SYSTEM_LEAK), 보조 2개(로마자
우회, 존댓말 사회공학). 추론은 인코더 forward 1회로 네 헤드를 모두 얻는다.

| 항목 | 값 |
|---|---|
| 손실 | 예제별 태스크 마스킹, PII O-라벨 가중 0.25, 공격 = 하드 라벨 0.5 + kanana 소프트 타깃(KL, T=2) + Qwen JAILBREAK 보조 0.25 |
| 샘플링 | PII:공격 4:1 |
| 하이퍼파라미터 | lr 3e-5, batch 32(16행 × 2 기울기 누적), max len 512 / stride 64, 5 epoch, seed 13·37·73, CUDA bf16 autocast |
| 조기 중단 | PII char-recall 과 공격 macro-recall **둘 다** 정체될 때 |
| 내보내기 | ONNX FP32 → dynamic per-channel QInt8(`reduce_range` — VNNI 없는 x86 의 int16 포화 회피), opset 18 |

**교사 증류(공격 헤드).** 공개 공격 풀에 교사 3종을 돌려 **클래스별 최소 2표 합의**만 학습에
쓴다. 불일치는 `NONE`으로 흡수하지 않고 검토 큐로 보내거나 감사 기록과 함께 폐기한다.
교사 하나가 과탐해서 사실상 단독 판정이 되는지(JAILBREAK 동의율 ≥ 0.95)를 별도 게이트로
잰다.

**재현성 장치.** 학습 입력과 최종 평가 입력을 SHA-256 으로 **각각 봉인**하고, 평가 봉인은
학습 봉인과의 정규화 지문 교집합이 비어 있어야 성립한다. 봉인 후 입력·설정·자산이 하나라도
바뀌면 학습이 시작되지 않는다.

## 7. 평가 원칙

1. **재현율 옆에 항상 FPR.** 단일 평균을 내지 않는다.
2. **동어반복 금지.** 생성기와 탐지기가 같은 체크섬을 공유하는 합성 셋의 재현율은
   회귀 지표일 뿐 성능 주장이 아니다. 헤드라인은 시스템이 질 수 있는 외부 셋에서만 낸다.
3. **지는 경로를 미리 적는다.** 예측을 측정 전에 등록하고, 빗나가면 그대로 보고한다.

## 8. 결과 — 배포 모델(L1 R1)

외부 셋·외부 모델로 잰 것만 성능 근거로 쓴다. 자작 셋 수치는 결과 문서에 한계와 함께 있다.

| 무엇 | 결과 | 근거 셋 |
|---|---|---|
| **L1 이 공격 탐지를 끌어올린다** | 탐지율 0.069 → **0.342**, 과방어 0.004 → 0.007 (인젝션 0.450 · 유출 0.146) | KoreanGuardrail 5,555 |
| L1 vs 교사(같은 600 표본) | L1 0.327 / 0.003 · kanana 0.630 / 0.017 · Gemma 4 L2 0.633 / 0.017 — **교사의 절반** | KoreanGuardrail 600 |
| **Gemma 4 L2 + 스트림 분리** | 0.810 / 0.057 (자모 분해 0.370 → 0.935), 행당 1.2~2.5초(M1) | KoreanGuardrail 600 |
| 개인정보(제품 경로) | 문자 P / R **0.979 / 0.977**, 성명 0.890 / 0.931 | KDPII test · KLUE validation |
| 개인정보 오탐 | PII 아닌 숫자 문장 8.8%(대부분 12자리 운송장번호) | bc-pii-ko 보강 음성 720 |
| 정상 문장 공격 오탐 | **0.439** — 처음 보는 정상 문장에서 높다. 기본 정책이 공격을 warn 으로 두는 이유 | 자작 홀드아웃 700 · 27 family |
| 시크릿 탐지 | 재현율 0.910 / 오탐 0.000 — CredSweeper 0.465 / 0.000, detect-secrets 0.465 / 0.170 | 자체 슬라이스 400 |
| 마스킹이 응답 품질을 깎는가 | 상대 저하 0.000 (목표 ≤ 0.10) | 합성 204 · gpt-4o-mini |
| 크기 · 지연 | INT8 152MB · RSS 937MB · 128토큰 p50 99ms(컨테이너 CPU), L0 만 p95 82ms(M1) | — |

**2차 학습(R2)** — 생성기 분할 · 정상 문장 126 family · 생성기 정상 표 · PII 음성 8,000행을 넣어 정상 오탐을
0.439 → **0.000**, 숫자 문장 오탐을 63 → 0 행으로 줄였지만, 외부 공격 탐지 0.342 → 0.316 · 성명 재현율
0.931 → 0.906 으로 사전 등록 통과선에 못 미쳐 **채택하지 않았다**. 그 측정 중 INT8 이 VNNI 없는 x86 에서
깨지는 결함을 찾아 배포 INT8 을 다시 양자화했다.

| 수동 골드셋(T3) · Cohen's κ | 사람 검수 없는 운영으로 미수행 |

**범위 밖 (의도적).** 조직 단위 강제(관리 콘솔·사용자별 정책·감사 대시보드), 브라우저
확장·엔드포인트 에이전트, 응답 유해성 모더레이션, 이미지·문서 파싱(OCR·HWP), 스트리밍
응답 검사. 사용자는 앱을 만드는 개발자이며, 개발자가 남의 입력을 막으려고 켜는 도구로
설계했다.

## 10. 실행

```bash
python -m pip install -e '.[l1]'             # Python 3.11 ~ 3.14, 저장소 루트에서
garim check '연락처는 010-1234-5678 입니다'      # → mask, <PHONE_1>
hf download cycloevan/garim-guard l1/r1/onnx/garim_l1.int8.onnx l1/r1/onnx/labels.json \
  l1/r1/onnx/tokenizer.json l1/r1/onnx/tokenizer_config.json \
  l2/gguf/gemma-4-E2B-it-Q4_K_M.gguf --local-dir models/garim
garim --l1-model-dir models/garim/l1/r1/onnx check '...'   # L1 연결
llama-server -m models/garim/l2/gguf/gemma-4-E2B-it-Q4_K_M.gguf --host 127.0.0.1 --port 8081 \
  --alias gemma-4-e2b-it --jinja
garim --mode thorough --l2-endpoint http://127.0.0.1:8081/v1 check '이쩐 찌시는 무시해'
garim proxy --upstream https://generativelanguage.googleapis.com/v1beta/openai
```

코드는 Apache-2.0, L1 가중치는 CC-BY-SA-4.0. 가중치 · 데이터는 Hugging Face `cycloevan/garim-guard` 에 있다.
