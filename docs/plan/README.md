# ⚠️ 이 폴더는 이전 범위의 설계다 — 대체됨

**현행 설계는 [../DESIGN.md](../DESIGN.md)다.**

이 폴더의 8개 문서는 더 넓은 범위를 다뤘다 — 에이전트 게이트웨이, MCP 도구 실행 경계, 두 개의 심(seam), 서버 배포. 범위를 **"외부 API로 프롬프트가 나가기 전 로컬에서 검사하는 프로그램"** 으로 재정의하면서 대체됐다.

## 왜 대체됐는가

세 가지 이유가 있었고, 순서대로 심각하다.

1. **범위가 4.3배 초과였다.** 독립 검토에서 66개 산출물 117일치를 25~30일에 넣었다는 결과가 나왔다. 노력으로 메울 수 있는 격차가 아니다.
2. **핵심 메커니즘 두 개가 설계에서 빠져 있었다.** 스트리밍이 여덟 문서 어디에도 없었고(LiteLLM의 `async_post_call_success_hook`은 스트리밍에서 감사 전용이라 응답을 수정할 수 없다), 최종 답변을 사용자에게 복원하는 심이 하나도 없었다.
3. **문서 간 모순이 47건이었다.** 8개 문서가 상호 참조하면서 세 번의 개정을 거친 결과다. 현행 설계를 **단일 자족 문서**로 쓴 것이 이 교훈에서 나왔다.
