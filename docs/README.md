## 평가 원칙 — 모든 결과 문서에 적용

1. **재현율 옆에 항상 FPR.** 단일 평균을 내지 않는다.
2. **동어반복 금지.** 생성기와 탐지기가 같은 규칙을 공유하는 자작 셋의 수치는 회귀 지표다. 헤드라인은
   시스템이 질 수 있는 외부 셋에서만 낸다.
3. **n 은 행이 아니라 군집이다.** 같은 기본 문장의 변주는 한 family 로 묶어 bootstrap 한다.
4. **지는 경로를 미리 적는다.** 판정 기준은 결과 전에 등록하고, 빗나가면 그대로 보고한다.
